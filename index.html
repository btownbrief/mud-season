    THE ROAD RULES

    Each hand is a stretch of Vermont road. Bid how many tricks you’ll take, then try to land on that number exactly.

    1. Hands run 7 cards down to 1, then back to 7. A new trump card flips every deal.
    2. Follow the suit that was led if you can. Highest trump wins; otherwise the highest card in the led suit takes it.
    3. Exact bid: 10 points + tricks taken. Miss: only 1 point per trick taken.
    4. Screw the dealer: the dealer bids last and cannot make everyone’s bids total exactly the number of tricks available.
